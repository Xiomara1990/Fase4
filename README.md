# Software FJ
## Sistema Integral de Gestión de Clientes, Servicios y Reservas

Proyecto académico de programación orientada a objetos en Python.

## Objetivo
Desarrollar una aplicación que gestione clientes, servicios y reservas,
con validaciones y manejo de excepciones para controlar los errores.

## Servicios previstos
- Reserva de salas.
- Alquiler de equipos.
- Asesorías especializadas.

## Gestión de la información
Los datos se manejarán mediante objetos y listas en memoria.
Se utilizarán archivos para registrar eventos y errores, sin bases de datos.
